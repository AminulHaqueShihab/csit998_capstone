CSIT998 Group 16 - Cryptocurrency Price-Direction Prediction Using LSTM Models and Media Sentiment Analysis

RESOURCES
All project resources are hosted on GitHub:

    https://github.com/AminulHaqueShihab/csit998_capstone

All data resources are available in the data/ folder of that repository:

    data/raw/binance/    Binance BTCUSDT daily kline archives (monthly ZIP files, January 2021 to August 2026)
    data/raw/gdelt/      GDELT Bitcoin headline exports (2021-2023 and 2024-2026, raw CSV)
    data/processed/      Cleaned price series, scored headlines, daily sentiment features,
                         the modelling table and the chronological train/validation/test splits

Other material in the repository:

    results/    saved predictions, metrics, walk-forward and lag-analysis outputs
    models/     trained LSTM weight files
    reports/    data-quality and split reports
    docs/       data sources, data dictionary and analysis notes
    web/        demonstration interface (live: https://crypto-price-prediction-demo.vercel.app/)
